# Expense Tracker

## About
An expense tracking website that helps users record their income and expenses and monitor their balance.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Features
- Add income transactions
- Add expense transactions
- Calculate total income and expenses
- Display remaining balance
- Save transactions in the browser

## How to Run
1. Open the project folder in VS Code.
2. Open `index.html` in a browser, or use Live Server.
3. Add income and expense transactions to track your balance.

## Learning Outcomes
Learn calculations, arrays, DOM manipulation, event handling, and Local Storage.
